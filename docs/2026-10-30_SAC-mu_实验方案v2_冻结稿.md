## 0 一段话版本

用 `ratio_p95`（P0 判 USABLE 的量具）做快环：周期内某步实测 ratio_p95 ≥ U 就跳过该次更新并结束本周期；慢环按 {4,8,16,32} 阶梯走（触发降一档、切满升一档）。对照臂：固定 µ=16/32/64、快环-only 消融 S、随机触发消融 R（冻结危险率表掷硬币）。主判据 P1（对 µ16 的配对差 ≥ +5pp 且 CI 不含 0）、护栏 P2、归因 P3，全部预注册。预算 31 GPU-h ≈ ¥65（上限 ¥104 含缓冲）。

## 1 方法定义

### 1.1 信号

控制变量 = `metrics.jsonl` 的 `ratio_p95` 字段（P0 卡 §3.4 判 USABLE：G1 ρ=+0.718、G2 SNR 6.31、G3 混淆 0.08、j=0 恒 1.0000 免锚点）。它量重要性比值尾部的 95 分位，与 current policy 同源计算、零额外前向。

### 1.2 触发语义（off-by-one 已钉死，读 `src/train.py` 确认）

`train.py` 每周期记 µ 行（mu_step 0..µ−1）。**第 si 行的 ratio_p95 是"做完 si 次更新后"的策略对 rollout 策略的比值，在第 si 步前向传播时测得、在该步 `opt.step()` 之前**。第 0 行恒 1.0（构造使然）；**最后一次（第 µ 次）更新之后的状态从不被测量**。

控制器语义由此确定：第 si 步（si≥1）前向算出 ratio_p95 ≥ U → 跳过该步反传写回与 `opt.step()`，本周期执行 si 次更新，记录该行（`sac_trigger=true`，参数空间统计置空）。**因此"触界"判定 = 周期内任一 si∈{1..µ−1} 行 ≥ U（any-hit，含最后一行）**——最后一行触发意味着省掉第 µ 次更新，是真实的提前停。

> **Revision R-1（2026-10-30）**：撤回 2026-10-30 上午讨论中的"early-hit（排除最后一行）"修正——该修正基于"最后一行=末次更新后状态"的错误假设，读码后证伪。校准回归 any-hit 口径：24 个 mu16_b256 周期在 U=1.0738 下命中 **12/24=50%**。第三方此前报的 13/24@1.070、11/24@1.075（any-hit）**经独立复验正确**。

### 1.3 慢环：阶梯走（Revision R-2）

v1 §4.3 的连续 AIMD（α 加性增、β 乘性减）**不可实现**：Br=4096=2¹²，b=Br/µ_max 必须整除且被 micro/group 整除（`config.validate` 硬约束），而 α=4 会走到 µ=20/24/28、β=0.75 会走到 12——全部除不尽。替代：

- 阶梯 `LADDER = (4, 8, 16, 32)`（µ=64 仅用于 P4 成本探针，不作主臂）；
- 每周期结束：触发 → 降一档；切满 → 升一档；下限 4、上限 32；
- 平衡条件：在 M=16 处需要 P(触发)=0.5 才驻留——这正是 U 的校准目标（F4：µ16=0.517 是最佳固定臂，控制器从那里出发）；
- 快环不变（周期内任意 si 可停），阶梯只约束慢环。

### 1.4 消融 R：随机触发（Revision R-3）

v1 §6 的"用同分布随机数替代 x"原样保留，实现为：触发判定换成**冻结危险率表掷硬币**——`HAZARD_M16 = (0,0,0,.0417,.0435,.0455,0,0,0,0,.0952,.1053,.0588,.125,.1429)`，即 24 个历史 mu16_b256 周期在 U=1.0738 下的逐步首触危险率（any-hit 率复现 12/24=0.5）。R 臂与 SAC 臂的 burn-in、阶梯动力学、b 结构完全相同，唯一差别是触发是否携带陈旧度信息。
已知近似（如实声明，不掩盖）：危险率在 µ16_b256 上测得，**原样套用到其它档位**（si>15 沿用 hazard[15]）；n=24，比例的抽样误差大。

### 1.5 记账与 LR 口径

- 行字段新增：`mu_plan`（本周期计划 µ）、`mu_executed`（实执行更新数）、`sac_trigger`、尾部诊断 `ratio_max` / `ratio_p99` / `ratio_over_high_frac`（同一张量，零额外前向；p95 管不住尾部，尾部直接记录）；
- 采样对齐：old_logp 前向对整个 Br 计划切分预计算，提前停只省"反传+更新"，**每周期采样量恒为 Br=4096**，与固定臂天然对齐；
- LR 视界：固定臂沿用原约定（R×µ）；SAC 臂 = R×µ_cap = 8×32 = 256；随机/消融臂同理。各臂视界不同是原 campaign 已有惯例（µ1=8 … µ16=128），非新引入；
- checkpoint 携带控制器状态（档位、周期号、步号、rng），resume 不许猜。

## 4 判据（重冻结，统计口径已钉死）

全部在**末 2 个周期**（r6–r7）的 pass_rate 上评（µ 臂末段口径与 Two Clocks 一致）。三 seed 配对（同 seed 相减）。

| # | 判据 | 档位 |
|---|---|---|
| **P1** | SAC 末段 pass − 固定 µ16 末段 pass 的 3-seed 均值 ≥ **+5pp**，**且**逐 seed 配对差的 bootstrap 95% CI（按 prompt 聚类重采样，参照 `c4_control_report.py` 口径）**不含 0**。两条同时满足才算成立 | 主判据 |
| **P2** | SAC 末段 pass ≥ 0.517（µ16 基线，F4）− 1pp 容差。护栏：不许用效果换稳定性 | 护栏 |
| **P3** | 消融 R 的末段 pass **不显著优于**固定 µ16（配对差 CI 含 0 或点估计 ≤0）。若 R 也显著上涨 → 效应来自 µ 抖动/均值而非陈旧度信号，**P1 即使成立也降级为"控制器等价于随机停止"** | 归因 |
| **P5'** | 诊断（不判成败）：①阶梯轨迹逐周期记录；②触发率按前/中/后三段（周期 2-3 / 4-5 / 6-7）分层上报；③是否触 cap/地板；④各臂实际壁钟。**触发轨迹是结果，不是调参依据** | 自检 |

机制级次要判据（**描述性，标注 exploratory**，不进主结论）：周期内 ratio_p95 斜率随训练段的衰减；触发步 si 的分布随段的移动；尾部诊断（ratio_max/p99/越阈比）与触界的关系。理论推导（smoothness 下界、AIMD 平衡）只提供动机与解读框架，**不构成任何判据的判成依据**；e_j 的"陈旧偏差/微批噪声"分解未经验证，禁止在报告里当作已证。

## 5 公平性口径与 P4 两分支

- 采样量：所有臂 R=8 周期 → 32,768 responses（P4 探针除外，它只验成本）；
- 壁钟：不封顶，如实报（§4 P5'）；
- 更新次数：不对齐——这是被优化的量；
- **P4 两分支**：P4 过（两探针周期耗时在 890s ± 25% 内）→ 固定 µ32/64 臂按 R=8 跑（上表）；P4 不过 → µ32 臂改按与 µ16 等壁钟折算周期数（并在报告披露采样不对齐），µ64 臂砍掉。**P4 只验成本，不验 ratio_p95 能否找到最佳停止点**——后者只能由 P1/P3 回答。

## 6 冒烟行为门（在 sac_s0 上判，先于其余全部臂）

1. burn-in 两周期 µ=16、无触发（metrics 可验）；
2. 周期 2–7 的触发率落在 20%–80%（超出 → 参数失配，回校准卡，不得硬跑）；
3. 阶梯轨迹始终在 [4,32]；
4. 无 loss/NaN 异常、checkpoint 正常落盘、resume 冒烟通过。
